# shared/ — Cross-skill taxonomy, schemas, and bridges

Single source of truth for concepts that exist in both `src/design-md/` (Node) and `src/ui-ux-pro-max/` (Python). Anything duplicated between those two should live here.

| Path | Used by |
|---|---|
| `taxonomy/archetypes.csv` | `ui-ux-pro-max` search (Python, reads CSV directly) and `design-md` extractor (Node, via `taxonomy/archetypes.json` generated by `scripts/build-shared.cjs`) |
| `schema/*.schema.json` | Validation of `tokens.json`, `style-fingerprint.json`, `quality-score.json` produced by `design-md` and consumed by `uipro-bridge.cjs` |
| `cli/uipro-bridge.cjs` | Post-hook bridge: ingests a successful `design-md` extraction and appends a row to `src/ui-ux-pro-max/data/extracted-references.csv` |

## Regen

After editing `taxonomy/archetypes.csv`, regenerate the JSON sidecar:

```bash
node scripts/build-shared.cjs
```

## Why a CSV + a JSON?

Python loves CSV (zero deps). Node prefers JSON (no parser cost in hot paths). The CSV is authoritative; the JSON is a build artifact and is git-tracked so consumers don't need the build step at runtime.
